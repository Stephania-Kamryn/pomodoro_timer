# Pomodoro Timer

A responsive Pomodoro Timer web application built using React and Tailwind CSS.

## Features

- Focus timer, short break timer, and long break timer
- Start, pause, and reset functionality
- Automatic switching between focus and break session after every 4 completed focus sessions
- Background gradients based on session type
- Session counter to track completed focus sessions
- Responsive and clean user interface

## Technologies Used

- React
- Tailwind CSS
- Vite
- JavaScript

## How It Works

- The timer starts with a 25-minute focus session.
- After each focus session, the app automatically switches to a short break.
- After every 4 completed focus sessions, the app switches to a long break instead of a short break.
- Users can manually switch between focus, short break, and long break modes.

## Deployment

The project is deployed using Vercel.
